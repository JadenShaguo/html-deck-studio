# HTML PPT 设计系统

English summary: This design system defines the fixed 16:9 canvas, safe areas, typography, color tokens, slide hierarchy, SVG diagram rules, screenshot layouts, and presentation controls used by HTML Deck Studio.

## 1. 画布与安全区

- 设计画布固定为 `1600 × 900`，比例 16:9。
- 浏览器仅缩放整个画布；不要通过响应式重排改变幻灯片内部结构。
- 安全区默认：左右 64px，上下 54px。标题、控件、结论和时间线都不得越界。
- 所有页使用同一安全区，不因内容多而压缩外边距。
- 幻灯片外层允许浅灰舞台背景，幻灯片本体保持白色或统一主题色。

## 2. 字体层级

默认以 2px 为阶梯：

| 用途 | 字号 | 行高 |
|---|---:|---:|
| 微型标签、坐标、页眉 | 14px | 1.4–1.55 |
| 正文、图注 | 16px | 1.5–1.65 |
| 卡片标题、强调句 | 18px | 1.4–1.55 |
| 模块标题 | 20px | 1.4 |
| 大数字、重点结论 | 22–24px | 1.3–1.45 |
| 页面唯一主标题 | 26px | 1.3–1.4 |
| 首页/尾页主题 | 38px | 1.18–1.3 |

- 页面唯一主标题才是本页最大字号。
- 首页和尾页主题是唯一例外，可使用 38px。
- 默认最小字号 14px；空间不足时重组内容，不能继续缩小。
- 中文优先使用系统黑体栈；英文代码、页眉标签使用等宽字体。
- 所有文字必须有明确行距，禁止重叠、相切或贴边。

## 3. 色彩与边框

推荐浅色主题变量：

```css
--paper:#fbfbf8;
--stage:#e8e8e3;
--ink:#26251f;
--muted:#807d75;
--line:#d7d5ce;
--orange:#f46a3b;
--orange-soft:#fff0e9;
--aqua:#278e84;
--aqua-soft:#eaf4f1;
--blue:#5278c8;
--blue-soft:#edf2ff;
```

- 浅色页面内禁止大面积黑色或深灰色底。
- 卡片使用白色、浅橙、浅青或浅蓝，不使用纯黑卡片。
- 全部装饰分割线统一为 `1px solid var(--line)`；不要同页混用粗细和深浅。
- 关键结构边框可以用主题色，但不超过 1.5px。
- 圆角统一使用 8、10、12 或 16px，禁止直角与圆角混杂。
- 投影无方向偏移：`0 0 24px rgba(30,30,24,.12)`。

## 4. 页面结构

- 页眉左侧：灰色小字页名，不带页码；下方统一分割线。
- 页眉右侧：编辑、上一页、下一页、全屏图标，垂直居中于顶部和分割线之间。
- 主标题区：一行主题标签 + 唯一主标题；右侧可放一句解释。
- 内容区：优先使用明确比例的 grid，不使用任意散落的绝对定位。
- 底部：一句结论 + 可点击时间线；不要加无意义灰色矩形。
- 尾页与首页对齐同一轴线、竖向装饰线、字体与留白。

### 视觉层级

每页从强到弱：

1. 唯一主结论。
2. 核心图或核心数字。
3. 解释维度。
4. 灰色补充与来源。

不要把六条同权列表放在两个大框里。需要比较时增加：

- 一个核心转型结论。
- 2–4 个清晰比较层级。
- 每层“旧 → 新”的对应关系。
- 结果证据作为次级支撑。

## 5. 图表、流程图与架构图

### SVG 强制规则

- 除真实截图外，全部图形使用内嵌 SVG。
- SVG 必须有 `viewBox`，由容器等比缩放。
- 箭头使用 `<marker>`，线条使用 `stroke-linecap="round"` 与 `stroke-linejoin="round"`。
- 回路优先使用圆角 path 或三次贝塞尔曲线。
- 箭头从节点边缘中点出发并抵达目标边缘中点。
- 线条绕过文字和卡片内容，不得从文字下方穿过。
- 同一图只使用 1–2 种线条颜色表达主流程与反馈。

### 图类型选择

- 先后与反馈：流程图。
- 层级、模块、职责：架构图。
- 同一字段跨对象映射：表格或映射图。
- 一对多影响：辐射图。
- 旧方式/新方式：逐层对应的转型图。
- 数量与比例：大数字 + 构成条/比例关系，不用装饰性饼图。

### 文本规则

- SVG 正文不小于 14px。
- 节点标题 16–18px。
- 一行标题保持单行；灰色说明允许两行。
- 专有路径或文件名使用等宽字体。

## 6. 产品截图页

- 截图自身不加大块背景框。
- 保持真实比例，按可读性决定宽高，不强行填满。
- 圆角 12–16px；无偏移柔和投影。
- 截图左侧或中间占 55%–68% 宽度；注释区占余下空间。
- 注释区在“图片右边缘—右安全区”之间水平居中，卡片应充分拉宽。
- 灰色场景说明放在注释区顶部，顶部不高于图片顶部。
- 三个注释卡片使用“序号 / 问题 / 一至两行答案”。
- 结果条放在注释区底部，使用浅色底和一句高亮结论。

## 7. 控件与时间线

- 控件只使用图标，悬停显示文字提示。
- 控件按钮 38–42px，圆形浅边框。
- 时间线每页对应一个可点击 segment，数量必须与页面数一致。
- 当前页 segment 使用主题色，其余使用统一浅灰。
- 悬停 segment 显示“页序 + 页面标题”。
- 时间线不能超出页面安全区，也不能出现比页面更多的 segment。
